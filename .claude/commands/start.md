Start of session. Do this before anything else:

1. Run `git pull` and tell me if anything came down.
2. Confirm the working directory matches the remote — if any file differs from
   what is in the repo, stop and tell me before touching it (lessons.md #9, #12).
3. Read `CLAUDE.md`, `AGENTS.md`, `memory.md` and `lessons.md`.
4. Tell me in 5 lines: where the project stands, what is unverified, and what I
   am blocked on.
5. Recommend what to work on and why. Then wait — do not write code until I say GO.
